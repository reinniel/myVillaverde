# Four-level map sheet update

- Added four snap levels: Peek, Browse/Compact, Place Preview/Expanded, and Full Details.
- Marker taps now open directly to the useful Place Preview level.
- Full Details expands almost to the search area and reveals address, phone, verification source, listing notes, and last-checked information.
- Selected markers are shifted upward after focusing so they remain visible above the sheet.
- Map controls fade while the sheet is fully expanded.
- Closing a place returns the sheet to the normal Browse level.
