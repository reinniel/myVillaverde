# Three-Level Map Sheet Update

The map bottom sheet now follows a simpler Apple Maps-style three-stage model:

1. Compact — title and summary while keeping the map in focus.
2. Preview / Browse — the default state and the state opened after selecting a marker.
3. Full — full-height, scrollable place details or browse results.

The old fourth snap level was removed. Marker taps now open the useful middle preview directly, full listing details appear at the top level, and the height indicator has three controls.

This build also keeps the compact 132 px barangay picker cards.
